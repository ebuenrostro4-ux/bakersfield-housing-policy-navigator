# Classroom demonstration

The old public quick-login demo is retired in the employee-workspace branch. No shared hardcoded password is supported. Use a separate local or approved hosted test environment with administrator-provisioned test accounts and public source text only.

Follow [the employee guide](EMPLOYEE_WORKSPACE.md) to demonstrate: sign in → import or paste a public policy → review extraction → analyze → human review → create tasks → update status and automatic progress → inspect document versions. General tasks also work without a policy.

Clearly disclose the AI mode. With live AI disabled, arbitrary documents produce excerpts only; do not present them as AI-written explanations. No confidential City information or real employee credentials belong in a classroom demo. The current public deployment stays unchanged until its separate migration is approved and verified.
